# ulixes-converter

Windows desktop edition of the ulixes converter by lingra.

**Freeware, not open source.** This repository holds no source code — only the
installer, published under [Releases](https://github.com/chrislingra/ulixes-converter/releases).

## Install

1. Open the latest release.
2. Download `ulixes-converter-setup-<version>.exe`.
3. Run it. No administrator rights are needed; it installs into your user profile.
